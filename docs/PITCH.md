## 1. The One-Liner
> **Sabha (सभा)** is the zero-cost, browser-native video collaboration suite providing complete Zoom feature parity on 100% free-tier cloud infrastructure.

---

## 2. The Problem
1. **The Subscription Tax:** Organizations pay $150–$250/year per user for video conferencing software that restricts recording, slashes time limits on free tiers, and enforces proprietary vendor lock-in.
2. **Heavy Native Bloat:** Desktop video apps consume gigabytes of memory, update constantly in the background, and fail to run efficiently on low-spec hardware in developing regions.
3. **Complex Self-Hosting:** Existing open-source alternatives (e.g. Jitsi) require dedicated multi-core Linux servers ($50–$150/month) and deep DevOps expertise to configure media bridges.

---

## 3. The Sabha Solution
- **Instant 1-Click Web Assembly:** No installation, no registration barriers, no 40-minute cutoffs.
- **Dual-Tier Hybrid Architecture:** Seamless transition between LiveKit Cloud SFU (50–100+ seats) and local WebRTC mesh fallback.
- **$0 Running Cost:** Operates entirely within free-tier quotas of Vercel, Firebase Spark, and Google STUN.
- **Zero-Cost In-Browser Recording:** Captures `.webm` video/audio locally on the client with zero cloud rendering bills.
- **Full Zoom Parity:** Host security controls, interactive whiteboard with PNG export, direct private chat, active speaker audio halos, and confetti reactions.

---

## 4. Market Opportunity & Timing
- **Total Addressable Market (TAM):** Global Unified Communications & Video Conferencing Market: **$14.2 Billion (2025)**, expanding to **$25+ Billion by 2030**.
- **Serviceable Addressable Market (SAM):** EdTech, open-source communities, developer hackathons, and small businesses: **$2.8 Billion**.
- **The Macro Shift:** Growing demand for lightweight, edge-native, zero-install WebRTC applications and self-hosted privacy compliance.

---

## 5. Technology Stack & Unfair Advantages
- **Modern Next.js 16 + React 19 + Tailwind CSS v4:** Ultra-lean modern web app.
- **Native Web APIs:** Web Audio API for frequency-based active speaker detection; `MediaRecorder` for client recording; `Canvas` API for whiteboards.
- **High Margin Potential:** Near-zero server compute cost creates an unfair margin advantage compared to incumbents.
